3. MİMARİ KARARLAR
================================================================

3.1 User ≠ Employee ayrımı (Fourth/Deputy/Workday standardı)
  - users tablosu: SADECE auth (email, hashed_password, role, is_active)
    + company_id ve branch_id FK'leri de users'da
  - employees tablosu: Tüm HR profili (tc_no, sgk_no, base_salary,
    bank_iban, hire_date, position, department, contract_type, ...)
  - employee.user_id nullable → sistem erişimi olmayan çalışan olabilir
  - Terminate: employee.is_active=False + termination_date=today
    + bağlı user varsa o da deaktive edilir
  - Rehire: employee.is_active=True + termination_date temizlenir
    + bağlı user varsa reaktive edilir

3.2 UserRole: SUPERADMIN / OWNER / MANAGER / EMPLOYEE

3.3 Hiyerarşi:
  Company → Branch → Employee → TimeClock / Payroll

3.4 Soft delete politikası:
  İçi dolu hiçbir kayıt hard-delete edilmez (yasal saklama zorunluluğu).
  Suspend (is_active=False) kullanılır.

3.5 Şirket/Şube askıya alma (lifecycle) kuralları:
  - Şirket askıya alınırsa: aktif çalışanların tümünün login'i kesilir.
  - Şirket reactivate edilirse: SADECE şubesi de aktif olan çalışanların
    login'i açılır (askıdaki şubedekiler kilitli kalır).
  - Bir şube, parent şirketi askıdayken reactivate edilemez.

3.6 Önemli import yolları:
  app.modules.employees.models.Employee
  app.modules.auth.models.User
  DİKKAT: auth klasöründe __init__.py YOK, employees'te VAR.

3.7 Dosya adı çakışması uyarısı:
  company ve employees modüllerinde ikisinde de router.py var.
  Kopyalarken hedef klasörü iki kez kontrol et (geçmişte karışıklık yaşandı).

5. TAMAMLANAN MODÜLLER
================================================================

5.1 AUTH — app/modules/auth/
  POST /api/v1/auth/register
  POST /api/v1/auth/login
  POST /api/v1/auth/refresh
  POST /api/v1/auth/logout
  POST /api/v1/auth/change-password

5.2 COMPANIES — app/modules/company/
  Tablolar: companies, branches
  CRUD + suspend / reactivate / delete
  Şirket/şube askıya alınca bağlı çalışanların login'i kesilir.
  Endpoints:
    GET/POST   /api/v1/companies
    GET/PATCH  /api/v1/companies/{id}
    DELETE     /api/v1/companies/{id}
    POST       /api/v1/companies/{id}/suspend
    POST       /api/v1/companies/{id}/reactivate
    GET/POST   /api/v1/companies/{id}/branches
    PATCH      /api/v1/branches/{id}
    POST       /api/v1/branches/{id}/suspend
    POST       /api/v1/branches/{id}/reactivate
    DELETE     /api/v1/branches/{id}

5.3 WORKFORCE — app/modules/workforce/
  Tablolar: shifts, shift_assignments
  ShiftStatus: draft → published | cancelled
  Endpoints:
    POST   /api/v1/shifts
    GET    /api/v1/shifts/branch/{id}
    PUT    /api/v1/shifts/{id}
    DELETE /api/v1/shifts/{id}

5.4 INVENTORY — app/modules/inventory/
  Tablolar: inventory_categories, inventory_suppliers,
            inventory_products, inventory_stock_movements
  MovementType: purchase / usage / waste / adjustment
  Endpoints:
    CRUD /api/v1/inventory/products
    GET  /api/v1/inventory/products/branch/{id}
    POST /api/v1/inventory/movements
    GET  /api/v1/inventory/movements/{product_id}

5.5 TIMECLOCK — app/modules/timeclock/
  Tablo: timeclock_records
  RecordStatus: open → completed | missing_checkout | adjusted
  ÖNEMLİ: employee_id FK → employees.id (users.id DEĞİL)
  Endpoints:
    POST /api/v1/timeclock/checkin
    POST /api/v1/timeclock/checkout/{record_id}
    GET  /api/v1/timeclock/branch/{branch_id}
    GET  /api/v1/timeclock/branch/{branch_id}/open
    PUT  /api/v1/timeclock/adjust/{record_id}
    PUT  /api/v1/timeclock/flag/{record_id}

5.6 EMPLOYEES — app/modules/employees/
  Tablo: employees
  ContractType: full_time / part_time / temporary / intern
  Endpoints:
    POST   /api/v1/employees                          → oluştur (+ opsiyonel user account)
    GET    /api/v1/employees/branch/{branch_id}
    GET    /api/v1/employees/company/{company_id}
    GET    /api/v1/employees/{employee_id}
    PUT    /api/v1/employees/{employee_id}
    DELETE /api/v1/employees/{employee_id}/terminate  ← admin şifre zorunlu
    PUT    /api/v1/employees/{employee_id}/reactivate

5.7 USERS — app/modules/users/ (sadece auth yönetimi)

    PUT    /api/v1/users/{user_id}
